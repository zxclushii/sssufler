# Суфлёр

Суфлёр слушает системный звук или микрофон, показывает расшифровку и отправляет вопросы в Claude Code. Ответ появляется в терминале поверх остальных окон.

## Запуск

1. Распакуй архив `suflyor-windows-x64.zip` в отдельную папку и открой `suflyor.exe`. В GitHub Actions этот архив находится в Artifacts завершённой сборки Windows portable.
2. Нужны Windows 10 версии 1809 или новее либо Windows 11 x64, Microsoft Edge WebView2 Runtime и Claude Code с выполненным входом. [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) · [Установка Claude Code](https://code.claude.com/docs/en/setup)
3. При первом запуске Суфлёр скачает Whisper, модель small-q5_1 (181 МиБ) и Silero VAD (0,8 МиБ). Прогресс виден в полосе статуса. Дальше распознавание работает локально и офлайн. Для ответов Claude нужен интернет.
4. Если Claude предложит доверять папке `workspace`, подтверди это в терминале. Когда собеседник заговорит, расшифровка появится над ним.

## Управление

| Клавиши | Действие |
| --- | --- |
| Ctrl+Alt+L | Включить или выключить прослушку |
| Ctrl+Alt+Space | Отправить накопленные фразы |
| Ctrl+Alt+X | Очистить накопленное |
| Ctrl+Alt+H | Скрыть или показать окно |

Переключай режим кнопкой рядом с индикатором громкости. В режиме «авто: вопросы» Суфлёр накапливает до восьми фраз и отправляет их вместе с вопросом. В «авто: всё» каждая новая фраза отправляется отдельно. В режиме «вручную» вопрос уходит по кнопке со стрелкой или горячей клавише.
Фразы, записанные при загрузке модели или распознанные с задержкой более 20 секунд, остаются в контексте до следующей отправки. Если ты печатаешь в терминале, автоматическая вставка ждёт паузу в две секунды.

## Настройки

Настройки хранятся в `config.json` рядом с программой. Старый файл от Electron можно положить туда до первого запуска. При запуске из папки без доступа на запись приложение выберет `%LOCALAPPDATA%\suflyor` и покажет путь. Испорченный JSON сохраняется под именем `config.bad.json`.

- В «Распознавании» выбери язык и модель. На медленном ПК попробуй `base-q5_1`. Ноль потоков означает автоматический выбор.
- В качестве источника выбери системный звук, микрофон по умолчанию или конкретный микрофон. Для внешнего сервера задай `whisperUrl` в файле настроек. В этом режиме аудио отправляется на указанный сервер.
- Пауза задаёт длительность тишины в конце реплики. Чувствительность помогает ловить тихий голос.
- В настройках Claude можно указать полный путь к `claude.exe` или `claude.cmd`, модель (по умолчанию `--model haiku`), системный промпт и шаблон сообщения с `{text}`. По умолчанию инструменты отключены. Галочка «Разрешить веб-поиск» разрешает Claude искать свежие сведения.
- После `/exit` нажми Enter в терминале, чтобы открыть новую сессию. Пока Claude закрыт, накопленные фразы остаются в окне.
- Если вводятся иероглифы или вывод прерывается, открой `logs/suflyor.log`. Если статус сообщает, что хоткей занят, освободи сочетание в другой программе и перезапусти Суфлёр.

## Сборка для Windows

Установи Visual Studio Build Tools с рабочей нагрузкой «Разработка классических приложений на C++» и Rust через rustup. Версию Rust задаёт `rust-toolchain.toml`. Для тестов интерфейса нужен Node.js 24. Файлы xterm уже включены в исходники.

Из корня репозитория выполни:

```sh
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo clippy --manifest-path src-tauri/Cargo.toml --locked --all-targets -- -D warnings
cargo test --manifest-path src-tauri/Cargo.toml --locked
cargo install cargo-audit --version 0.23.0 --locked
cargo audit --file src-tauri/Cargo.lock
node --test ui/
cargo install tauri-cli --version 2.12.6 --locked
cargo tauri build --ci -- --locked
```

Готовый файл лежит в `src-tauri/target/release/suflyor.exe`. Для загрузки движка используется сборка `b5454` из описания релиза v1.9.5. Программа сверяет SHA-256 архива и штатных моделей перед установкой. [Релиз whisper.cpp](https://github.com/ggml-org/whisper.cpp/releases/tag/v1.9.5)

## Проверка на живой Windows

| Что проверить | Как воспроизвести |
| --- | --- |
| Фокус окна | Набирай текст в Блокноте. Скрой и покажи оверлей с помощью Ctrl+Alt+H и продолжай печатать в Блокноте. |
| Прозрачность | На фоне светлого окна меняй прозрачность с 40 до 100%. Смотри на фон терминала и буквы. |
| Пауза системного звука | Поставь видео на паузу посреди реплики. Расшифровка должна появиться после заданной тишины и времени распознавания. Затем переключи устройство вывода и проверь, что новые реплики приходят. |
| Простой и задержка терминала | Выключи прослушку, дождись окончания загрузки. В диспетчере задач наблюдай CPU процесса suflyor.exe в течение минуты. Цель — менее 1% и отзывчивый ввод. |
| ConPTY и Claude | Проверь длинный ответ на русском, два вопроса подряд, ввод вручную и повторный старт после /exit. Отдельный тест проверяет 100 000 букв, их UTF-8 и код выхода. |
| Чистая Windows 10 | Запусти exe на 1809 без WebView2, затем повтори после установки Runtime. |
| Микрофон | Запиши одну реплику в комнате с шумом через старую и новую версии. Сравни пропуски и ложные срабатывания, затем проверь две минуты музыки без вокала. |
